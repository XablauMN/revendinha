# Cores dos gráficos
Para os gráficos da Home, pode usar cores que casem com o design geral ou esses:
Azul: #52AD9C (Para Lucro, por exemplo. Pode ser um azul mais escuro se o fundo for claro)
Verde: #3F9B0A
Vermelho: #DD1C1A

# Sistema de Fontes
Use a biblioteca @fontsource/manrope e @fontsource/open-sans (ou @fontsource/inter, use a que julgar melhor se encaixar no contexto). Configure o Tailwind (tailwind.config.js) para usar Manrope como font-sans nos cabeçalhos e Open Sans no corpo.
